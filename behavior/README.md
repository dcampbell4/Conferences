# Effort Tracker

A one-tap classroom behavior/effort logger built from the *Effort Tracker 2026–2027* spreadsheet.
It uses the same five indicators, the same CON / INT / POS system and the same weighted-flag grading.

## How to use
1. **Setup tab.** Upload your roster (.xlsx or .csv with a "Student" or "Name" column; a "Class"/"Period" column splits classes). You can also upload the original Effort Tracker workbook, and its Daily Log entries come across too.
2. **Pick a class** from the buttons at the top.
3. **Log tab.** **Tap** a coloured button = CON flag. **Press and hold** = INT flag. **★** = positive moment.
   A message pops up after each tap with **Undo**, **Make INT** and **Note** buttons.
4. **⧉ Pop-out widget.** Opens a small always-on-top window (Chrome or Edge) that you can keep over Google Slides or PowerPoint while presenting.
5. **Dashboard tab.** Monthly tally, levels and overall grade. Click a student to see the rubric wording for a conference, and print it if you like.
6. **Records tab.** Edit or delete entries, add notes, and export CSV in the same columns as the spreadsheet's Daily Log.

## Privacy and sharing
- All data stays in the browser on the device you use it on (localStorage). Nothing is sent anywhere.
- Colleagues can use the same link. Each teacher uploads their own roster and keeps their own data.
- Use **Setup → Download backup** regularly, and to move data to another computer.
